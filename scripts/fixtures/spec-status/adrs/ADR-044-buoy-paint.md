# ADR-044: Fixture Buoy Paint

Every channel buoy is repainted in the same fortnight each spring so a pilot reads one
season's colours along the whole approach.

## Decision

- The paint lot is opened on the first buoy and used up before the next lot is broached.
- A buoy that has lost its number is repainted before its colour.
