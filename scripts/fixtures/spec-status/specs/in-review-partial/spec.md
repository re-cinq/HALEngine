# fixture chandler's counter

| Field  | Value                |
| ------ | -------------------- |
| Issue  | example/repo#17 |
| Status | In Review            |

The chandler's counter sells oakum and pitch against a season ledger, so a boat owner settles
up once in the autumn rather than on every visit.

## The rule

- Oakum is weighed on the counter scale and never estimated by the handful
  ([validated by](../../../../../src/orchestration/chatOrchestrator.test.ts#L14)).
- Pitch is sold by the sealed tin, so a part-used tin stays with the yard.
