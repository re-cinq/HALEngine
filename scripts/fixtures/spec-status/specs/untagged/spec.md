# fixture bell foundry

| Field | Value                |
| ----- | -------------------- |
| Issue | example/repo#17 |

The bell foundry casts one bell a month and tunes it against a tuning fork kept in the
foreman's desk.

## The rule

- A bell is tuned against the fork before it leaves the yard.
- A bell that will not hold its note is melted down rather than sold.
