# fixture net loft

| Field  | Value                |
| ------ | -------------------- |
| Issue  | example/repo#17 |
| Status | Accepted             |

The net loft above the ice house dries one crew's nets at a time, so a torn net is mended on
the floor it came off rather than carried across the yard.

## The rule

- A net is hung the length of the loft and never folded to fit
  ([validated by](../../../../../src/orchestration/chatOrchestrator.test.ts#L14)).
- A mended net is marked with the mender's tag before it leaves the loft.
